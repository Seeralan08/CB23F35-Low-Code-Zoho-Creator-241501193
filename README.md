## Implemented demonstration

- Twelve-field maintenance request form with a required unique ticket reference.
- Category, priority and status choices; default status Reported.
- Validation of date order, future reported dates, description length, assignment and resolution notes.
- Saved-record list and status Kanban board.
- Six dashboard counters that recalculate when the page loads.
- Valid submission, duplicate-reference, rejection and record-update tests documented in the report.

The November 2, 2026 review showed 8 total requests, with statuses 1 Reported, 3 Assigned, 2 In Progress and 2 Resolved. Overdue unresolved was 1 and changes with the current date.
